# 背了么

Vue 3 + Node.js + MySQL 的学生英语学习项目，仅用于非商业学习与展示。

## 本地启动

需要 Node.js 22 或以上、MySQL 8。

1. `npm ci`。
2. 将 `server/.env.example` 复制为 `server/.env`，设置数据库连接和固定的 `JWT_SECRET`。首次设置 `AI_KEY_ENCRYPTION_SECRET` 后请保持不变；已有密钥依赖当前加密配置，不要随意轮换。
3. `npm run db:setup` 创建结构并导入词书；`node server/src/db/importIelts.js` 可单独导入项目保留的雅思词表。
4. `npm run start:all`，打开 http://127.0.0.1:5173/ 。

已有安装升级先运行 `npm run db:migrate`，再重启后端。

## API 与账号绑定

注册登录后，在“设置”里保存一次自己的 API Key。服务端按登录账号加密存入 MySQL，不在浏览器存放 API Key 明文，也不会通过接口回传明文。

刷新、重新登录会自动恢复当前账号已绑定的 API 配置。输入框留空代表沿用已经保存的同服务商 Key，可直接更换模型、获取模型列表或测试连接。切换账号会清理上一账号的页面缓存；数据不会在不同账号间共享。API 连接失败时可以重新测试，不必重复粘贴。

请备份自己的数据库和服务器加密配置。GitHub 只保存代码、测试和公开词库，不包含个人 API Key、数据库或 `.env`。

## 已有功能

- 分层自适应词汇测评、保存恢复与复测。
- 背词、错因分析、复习计划；数字键 1–4 选择、空格继续。
- AI 自定义情境对话：描述练习需求，生成角色、交流目标和场景单词，含搭配、释义与例句，自动保存到当前账号的“我的场景”。
- 内置点餐、问路、bank 多义、酒店入住、求职面试、购物和校园场景；支持收藏、搜索、回看历史和同一场景重新练习。
- 自由交流与任务练习两种方式，可选 8／16／24 轮；文字／麦克风输入、四级帮助、可调纠错严格度、结束复盘与薄弱词回流。未收录的自定义词仍可在场景词汇和短句练习中回顾。
- 对话小结支持下载 PDF 或 PNG 图片，包含词汇表现、纠错与短句参考答案；PDF 自动按 A4 分页，文件在浏览器本地生成。导出沿用当前界面的主题色与字体，用于标题、重点和装饰，并调整浅色文字的对比度。较长小结可使用 PDF 导出。
- 再次进入情境练习会恢复当天最后查看的对话或小结；北京时间跨天后先展示场景选择，历史记录保留并可手动恢复。
- 雅思等词书、词根词缀拆解与记忆库。
- 暖纸、磨砂暗黑和林间主题。

麦克风识别需要独立的语音服务配置；AI 回复朗读使用浏览器自带能力。账号注册、API 配置和真机验收见 [情境练习接入待办](docs/情境练习接入待办.md)。

## 验证

`npm run build` 构建前端。`npm run test:server` 使用独立的 `beileme_test` 数据库执行测试，会重建该测试库，不要把开发数据库配置为测试库。AI 测试使用模拟服务，不产生模型调用费用。
# 管理员共享语音识别

管理员在「偏好设置 → 语音服务」统一填写硅基流动 Key、开启服务，并设置每位用户的使用限额。
服务固定使用 `FunAudioLLM/SenseVoiceSmall`。普通用户登录后可从导航进入「语音转文字」直接录音，
不需要个人语音 Key，也不需要先配置文字模型或创建情境对话。情境对话中的原有语音输入也共用此配置。

首次安装或更新：

1. 按本文原有说明配置数据库、安装依赖，再执行 `npm run db:migrate`（包含新增的共享配置表）。
2. 在网页注册管理员将使用的账号，然后在服务器项目目录运行 `npm run admin:grant -- 该账号邮箱或手机号`。
   这个命令仅修改本机 `server/.env` 中的 `ADMIN_USER_IDS`，不能通过注册接口自封管理员。
3. 重启后端，用该账号登录，打开「偏好设置 → 语音服务」填写 Key，测试账号连通性后保存。
4. 普通用户登录同一套服务器即可使用。录音权限需用户主动允许，网站需使用 HTTPS 或 localhost。

Key 使用后端 AES-256-GCM 加密存入数据库，管理接口也不回传明文或密文。保留好
`AI_KEY_ENCRYPTION_SECRET`（未设置时使用 `JWT_SECRET`），更换加密主密钥后需要重新填写语音 Key。
环境变量中的 `SPEECH_*` 仍可作为未设置后台配置时的兼容配置；管理员保存后以后台配置为准，
关闭服务时不会回退到环境变量而意外继续识别。配置重启后保留；每人每日/每分钟的限额计数仍为单进程内存计数，
服务重启会重置，多实例部署需改用共享限流存储。

「所有用户可用」指连接同一后端的登录用户。GitHub 仅分发源码，不分发密钥；其他人单独部署时，
需要由那台服务器的管理员配置一次。若希望用户只需访问网址，应统一部署前后端与数据库。
语音转写不提供音素级发音评分；AI 情境生成与回复仍需配置文字模型。

## 组员同步与测试（2026-10-29）

本版本包含独立单词本（默认本、自建本、中英对照与遮罩回顾）、麦克风选择、原始收音、音量波形与录音回放，以及对话校验恢复。回顾页仅保留错词和短文，单词本从侧边栏进入。

首次下载：安装 Node.js 22+、MySQL 8，启动 MySQL，然后在项目目录执行：

```powershell
npm ci
Copy-Item server/.env.example server/.env
# 编辑 server/.env，填写自己电脑的 DB_USER、DB_PASSWORD，设置固定的 JWT_SECRET。
npm run db:setup
npm run start:all
```

打开 http://localhost:5173/，注册自己的账号。文字 API 在网页偏好设置里配置；语音 API 可填写本机 `server/.env` 的 `SPEECH_API_KEY`（模板已填写硅基流动地址和 SenseVoiceSmall 模型），或按上面的管理员共享语音说明配置。密钥可稍后填写，没有语音 Key 时仍可打字。

已克隆过项目的组员，先保存自己的代码改动，再执行：

```powershell
git pull --ff-only
npm ci
npm run db:migrate
npm run start:all
```

更新前先停止旧的前后端进程，再重新启动，避免继续使用旧接口。Windows 也可在配置好依赖和数据库后双击 `start-beileme.cmd` 启动服务，再自行打开上面的网址。

源码、配置模板、公开词库与数据库结构通过 GitHub 同步；`node_modules`、构建产物可由命令重建。个人数据库、账号、收藏、场景、学习记录和已绑定的 Key 不随源码分发。各自本地部署拥有相同功能，数据独立；无需复制他人的数据库密码、JWT_SECRET 或加密主密钥。请勿把 `.env`、数据库备份或任何实际 API Key 提交到仓库。
