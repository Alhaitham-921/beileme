# 学习排行与安卓导航

排行榜从侧栏或「更多 → 学习排行」进入，也可以放到安卓底栏。

- 累计榜：历史实际作答的新词、复习词，按 `words.spelling_norm` 跨词书去重。
- 每日榜：按应用业务时区（默认北京时间 UTC+8）的当天实际作答去重。昨天学过的词今天复习，可计入今天，但累计总数不会重复增加。
- 单词学习量不代表已经掌握；查词、游戏、阅读不计入此次排行。答错也属于实际学习。
- 同分并列（1、1、3），展示前 50 位；本人不在前 50 时仍返回本人排名。
- 仅登录后可访问，其他账号显示学习编号，不返回昵称、邮箱或手机号。
- `GET /api/v1/stats/leaderboard?period=total|daily` 返回 `period/date/participants/items/me/rule`，不缓存私人响应。不接受客户端上报的数量。

目前不包含经验值、等级或任务奖励，待任务模块确定后单独对接。

应用导航只保留主要学习模块：单词本、情境、查词、温故知新、词根词缀、学习足迹、学习排行和设置。已移除独立口语练习和雅思专项页面，语音输入继续用于情境对话。

搭配练习在「单词本 → 错题本 → 搭配错题与到期复习」，阅读巩固和看图回忆在「温故知新」。它们不再占据侧栏、「更多」或底栏自选项。旧底栏里已删除的模块会自动替换，保留其他有效选择；旧搭配、阅读链接会跳转到对应子页面并保留单词或文章参数。

手机首页点顶部「背了么」或在空白区域右滑打开左侧导航，支持返回键、遮罩、左滑和关闭按钮收起。其他页面点品牌返回首页。右滑忽略表单、按钮、链接、多指和上下滚动，不抢占学习卡片的手势。侧栏保持与电脑一致的模块入口，移除独立的背单词导航项。

设置 → 学习环境中配置安卓底栏最后四个位置，只有「今日」固定。设置按账号保存在本机，不跨设备同步；不可重复选择同一模块。旧版三个可选项会保留并补上第四项。

两端从首页「复习旧词」「学习新词」直接进入作答，无中间选择页。没有到期旧词时在首页提示；跳过旧词需确认实时待复习数量；直接访问学习页优先恢复未完成进度，否则先旧词后新词。复习结束且今日仍有新词时直接进入新词；今日新词目标完成后仍可加学。

## 自定义头像

设置 → 学习环境上传 JPG/PNG/WebP，最大原图 8 MB、2000 万像素，预览中心裁剪后保存。客户端先缩小，服务端再次验证、裁剪为 256×256 WebP 并去掉元数据；处理后的上传上限 512 KB。头像保存在数据库，备份和多端登录可直接恢复，无额外文件卷。

头像会显示在登录用户可见的排行榜和个人侧栏，设置中可恢复默认头像。不公开邮箱、手机号或昵称。`PUT /profile/avatar` 接收 `{image:base64}`，`DELETE /profile/avatar` 只操作当前账号；`GET /profile/avatars/:id/:revision` 需登录。更换头像产生新版本地址，旧地址失效。上传每账号每小时最多 30 次。

部署需要追加迁移 `033_dialogue_illustrations.sql`、`034_user_avatars.sql`，保留既有数据。
