# 自测历史关联与综合解释

入口为「选择学习起点」的短测结果页。首次及后续每次自测均可选，不设置强制周期、不因未测拦截学习或复习；用户可以直接学习，也可暂停自测后再继续。自选档位及“采用测评建议”仍由用户决定。

## 所有用户的自动分析

- 每次作答保存题目、目标词义、选项、正确答案、用户选择、“不认识”、用时、题目用途及实际词库 ID。题目快照不会随词书编辑或题库更新而改变。
- 完成后自动读取基础分析接口，生成并持久化报告。历史按当前账号和当前词书关联，最近二十次可比较记录参与分析；方法或已知题库版本不同的分数不直接混合。
- 对比各档题目的正确数、题量和正确率；反复错误按“拼写＋所测词义”关联。本次重新答出只视为本次改善，不认定长期掌握。
- 增加独立的综合学习建议和多次分档趋势：从最近二十次可比较历史中，取最近五个测试日；同一天只用最后一次，保留完整记录供查看。至少三个不同测试日才描述跨次上升、下降、相近或波动，不把同日刷题当成持续进步。
- 综合建议结合最近三个测试日的档位支持、分档波动及近期练习证据。最近三日中至少两次与本次建议一致、没有下降或波动提示且没有触发练习巩固规则时，可提供用户自愿采用的综合档位建议；历史不足、结果波动或练习薄弱时分别提示积累依据、观察或巩固，不自动改档。
- 练习巩固提示采用产品规则：日常作答至少十次且正确率低于百分之五十五，或搭配至少五次且正确率低于百分之六十，或延迟复测至少五次且独立答出率低于百分之六十。缺少练习证据时明确保留判断；这些阈值不是正式能力标准。
- 日常学习与复习、搭配填空、已完成的延迟复测分别统计，范围是测试完成前近三十天的当前词书。报告以本次完成时间为界保存；以后查看历史报告不会混入未来学习数据。
- 后续短测在原二十四道分层题、可能的四道边界题之后，追加最多四道有可靠快照的历史薄弱题；不重复当前卷已测的目标词。这部分单独反馈，不参与分档计分。
- 已关联实际词库的自测错词进入账号错题本，可直接组成选词复习，也可进入错词回忆和延迟复测。正确的自测答案不自动增加长期掌握度。
- 旧记录保留原统计；没有题目快照时不倒推题目，也不将原来的合成题号当成词库编号。不同卷仍属试用题，未经正式等值校准，变化只供参考，不换算精确词汇量。

## 可选的文字 AI 解释

- 仅用户点击 `POST /assessment/placement/:id/explanation` 后调用。沿用有效个人 Key → 平台 Key → 无可用 Key 的顺序；读取页面和基础报告不会调用模型。
- 无 Key、额度不足、超时、返回内容无效时，基础比较及练习建议继续可用，页面如实提示。没有模型时不把规则分析标为 AI 解释。
- 文字模型接收跨日成绩序列、系统核对的结论及练习建议，选择重点和组织顺序。模型只返回结论和建议编号；服务端根据对应证据呈现解释，不展示模型自行添加的事实或自由文本。这比仅检查“引用编号存在”更严格：没有历史、方向相反或缺少练习记录时，不存在相应的可选结论。
- 校验同时检查结论适用性、综合结论必选、练习优先项、引用范围、重复项及多余字段。虚构进步、词汇量或强制改档的返回不会成为报告，仍保留基础分析，由用户决定是否重试。保存的解释也会重新核对结论编号，并由当前证据重新呈现文字。
- 解释按用户及自测记录持久保存，重开页面或重复点击复用结果；同进程合并并发请求，数据库租约阻止多实例重复生成。调用失败后由用户手动重试，不自动放大额度重试。
- 接入现有文字 AI 输入、摘要输出和思考设置。`AI_DAILY_ASSESSMENT_ANALYSIS_QUOTA` 默认平台每日三次，个人 Key 沿用现有倍数，无限档位沿用现有规则；另有每分钟四次保护。实际及未知用量记入 `ai_usage.assessment_analysis`，在设置页展示。
