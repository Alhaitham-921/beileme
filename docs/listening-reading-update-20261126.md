# 听读空间更新（2026-11-26）

## 使用方式

- 英语名著按屏幕宽高、字号测量后分页，支持上一页、下一页、本章跳页及跨章翻页。桌面支持方向键；触屏查词模式支持横滑。
- 阅读位置保存为章节、段落、字符偏移，不用设备相关页码。屏幕或字号变化后，重新定位同一段原文。旧版只有段落的记录仍兼容，偏移默认为 0。
- 长按单词两秒查释义。手机在“查词”和“选句分析”之间切换，选句模式保留系统文字选择手柄；桌面可直接拖动原文。选好后点击“AI 分析选句”，解释句意、句式结构与本句的词语用法。
- 偏好设置 → 外观 → 名著阅读可以开启“每页英文后显示中文解释”，阅读页也有同一账号偏好的快捷开关。默认关闭。开启后停留在新页 700 毫秒再发起文字 AI 请求；结果保存到账号，下次同样的原文范围直接读取。界面说明 API 用量以及非出版译文。
- 情境精听移除重复的真人有声书卡片，章节真人朗读仍保留在阅读页内。提交理解题后可主动点击“AI 分析选项与错因”。基础判分无需文字 API。

## 调用与存储

`ReaderView / LibraryView → library API → libraryAssistanceService → libraryAssistanceRepository / 文字模型适配层`

迁移 `044_library_assistance.sql` 仅新增账号阅读偏好与 AI 解释表，不删除、重建原账号或学习记录。

服务端从规范书籍文本核对页范围和选句，AI 引用必须是原文连续片段。听力分析只读取当前账号提交的 attempt，并从规范材料取题目、选项和答案；不能由客户端覆盖判分。错因描述是待验证的可能性，不等于能力诊断。

解释按账号、类型和来源内容 SHA256 保存；同进程相同请求合并，数据库租约防止多进程重复发起。生成超时后可主动重试。缓存读取不新增模型调用，原生成用量与本次用量区分显示。未接入文字 API 时给出设置入口，英文阅读、词库查词和基础理解题仍可使用。
