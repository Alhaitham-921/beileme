# 连续练习、学习负担与等待恢复（0.2.5）

## 情境小结 → 下次练习

情境页的小结旁新增“下一次练什么”，本组结束页也展示近期任务。依据已结束对话中的目标词表现生成最多五个任务；最终纠错证据优先于对话中显示的使用勾选。原句只能引用用户真实输入，未使用的词不虚构原句、不直接记为答错。

每个任务保留来源、具体纠错（有证据时）、短句提示、参考表达和下次建议检查时间（生成后一天）。短句可保存到数据库，也可单独请求 AI 批改。批改接受符合题意的多种表达，区分表达正确、需要修改和未完成题目要求；批改反馈不计入掌握记录。词库中能匹配的词可直接复习，未匹配的词仍可进行短句或情境练习。

“提前练习”可以把目标词安排到下一轮单词学习，或选择日期并通过时分滚轮设定时间。自选时间首次默认建议检查时间后三小时，若已过则定位到下一可选分钟。到时间的安排优先进入新开的单词学习组，实际作答后消除该安排。词库未收录的目标词支持自选短句练习时间。

“换个情境再用一次”将任务关联到新生成场景，保留原目标词并要求不同地点。新对话结束后，只有服务端最终证据认定该词独立使用，且场景地点不同，原任务才记录迁移成功；这不等于长期完全掌握。请求重试、回看小结不会重复建立任务或重复修改原复习记录。

现有最近十份已完成小结会按需补充任务；打开具体历史小结时也可补充该份。列表最多展示二十项，界面展示前五项，紧凑入口前三项。按账号隔离。

## 自主安排本次学习

学习入口保留“复习旧词／选择新词”两个按钮。复习旧词每组最多十个，优先带上到时间的手动安排，其余名额按到期列表取词；今日计划已完成也可继续处理其余到期词。结束页显示实时剩余数并提供继续下一组。

选择新词保留每日新词目标，完成后可自主加学新词。旧版的混合模式和时长参数在 API 中保留兼容，但学习入口不再展示时长选择和长篇说明。

“先学到这里，保存进度”显示本组已答与剩余数量。已答记录及未答队列保留在服务器；应用重开后也能恢复最近有效暂停的一组，不被之后创建的空组或完成组遮住，不把未答词计为完成。结束接口会在事务锁内拒绝结束仍有未答词的组；下一组请求失败时，前端保留原组结果与重试上下文。新建另一组代表重新安排，已答记录仍保留。卡片显示安排原因与本次到期信息，提交作答后显示新的下次复习时间。

## 等待、取消与重试

语音输入区分整理录音、上传、语音服务识别三阶段。失败、超时或取消等待时保留当前页面的录音，支持回放和提交同一段录音重试，保留可编辑输入。用户开始新录音、离开页面或关闭应用后不保留该临时录音；录音不额外写入磁盘。

情境生成、错词卡片生成支持取消等待，并保留原需求。取消表示停止客户端等待，服务端或模型可能继续完成；因此应先刷新已保存场景，或重试读取错词缓存，不能承诺取消后一定不计费。情境对话原有的草稿保留、进度恢复及小结后台生成/重试继续有效。

同一账号同时请求相同批次卡片时共用一次生成任务；近期已生成卡片优先读缓存。个人错因卡片仅复用本账号缓存。旧请求晚到不会覆盖新的生成结果。

朗读在请求音频阶段显示“正在准备朗读音频”，停止朗读也取消等待并防止迟到音频播放；保留原有 Kokoro 音频缓存。

## 部署与验证

用 npm run db:migrate 应用学习连续性迁移 020_learning_continuity.sql 和情境练习排程迁移 023_practice_followup_schedule.sql。启动新版后端后执行 npm run android:build 和 npm run android:install。更新安装保留账号与应用数据。

回归测试使用独立的 beileme_latest_20261102_test 数据库，模拟 AI，不调用付费模型；包含任务引用、账号隔离、短句保存、完整迁移流程、任务限量、暂停恢复、录音失败及取消重试、并发卡片去重与个人缓存验证。
