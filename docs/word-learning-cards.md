# 单词用法卡片与自动发音（0.2.7）

## 学习流程

先看单词并自动朗读，再选择释义。答对和答错都会展示同一张用法卡，提供例句、短语搭配、形近词和近义词。作答与翻页不等待资料下载或 AI 生成；网络失败也不影响学习进度。原有词根词缀、收藏、手动重播和间隔复习继续保留。

参考不背单词官网的语境例句，以及扇贝官方应用介绍中的例句和助记设计，采用“先回忆，再看语境与用法”的组织方式。本项目不复制其他软件的界面或例句库，也不宣称现有例句是历年真题。

- 不背单词：https://www.bbdc.cn/
- 扇贝官方 App Store：https://apps.apple.com/cn/app/id698013609

## 资料来源与费用

1. 当前词书已有例句，以及项目原创的 50 个常用词双语例句和搭配（server/data/wordUsage.js）。小型入门集不代表覆盖全部词书。
2. 已经手动生成并保存在当前账号的 AI 卡片，读取无需新调用。
3. 当没有例句时查询 Free Dictionary API（https://dictionaryapi.dev/），不需要密钥、不调用收费 AI。只收录附带有效 HTTPS 许可链接的返回内容，并展示原词条与原始许可证。免费词典并不保证每词都有例句，也不提供完整的中英双语搭配库。
4. 缺失资料会如实显示“暂未收录”，用户可点击“AI 补充例句与搭配”。此操作沿用现有服务、额度、缓存和费用提示，未点击时不会生成。AI 产物标明来源，不伪装为权威词典。提示词缓存版本为 usage-v2，避免误读旧版缺少搭配的卡片。

免费词典原文缓存存入新增的 word_learning_dictionary_cache，按拼写跨词书复用，正缓存 30 天，词条缺失缓存 7 天；失败短暂退避。同词并发去重，外部查询同时最多 4 个、5 秒超时。私人 AI 卡片仍通过 generated_contents 按 user_id 读取，不进入公共词典缓存。新增迁移 022 仅建缓存表，不更改学习记录。

## 错词记忆图

在背词中答错或选择「不认识」后，可以选择一条词义并点「生成记忆图」。生成期间可继续答题，完成后可从「单词本 → 错题本 → 查看记忆图」回看；再次复习时，已保存的图在提交答案后展示。图片按账号、单词和词义保存在 MySQL，生图服务只收到要画的场景和绘制要求。

默认使用硅基流动的 `Kwai-Kolors/Kolors`。本地安装依赖并运行 `npm run db:migrate` 后，在 `server/.env` 设置 `WORD_IMAGE_API_KEY` 并重启后端。Docker 部署在 `deploy/.env` 配置同一项，再运行 `sh deploy/compose.sh up -d --build api`。如果之前设过生图地址或模型，改为 `WORD_IMAGE_BASE_URL=https://api.siliconflow.cn/v1` 和 `WORD_IMAGE_MODEL=Kwai-Kolors/Kolors`。服务端会下载图片并转成 WebP 保存，方便之后回看。[硅基流动 API 密钥](https://cloud.siliconflow.cn/account/ak) · [生图接口](https://api-docs.siliconflow.cn/docs/api/images-generations-post)

生成前，文字 AI 根据所选释义、词性、例句和误选项设计场景。动词画出动作和结果，形容词突出可见特征，副词通过姿态或动作表现方式，抽象词用具体情境助记。图下「这样记」说明最关键的画面细节。旧图可在错题本中点击「重新生成记忆图」升级；生成失败时原图仍可回看。两个接口各自按服务商计费。

新图保存为最长边 640 像素的 WebP。轮询只读取状态，图片经独立的登录接口下载并在本设备缓存；更新图片会换一个地址。升级时先运行 `npm run db:migrate`，迁移 027 为已有图片补上版本标识，不删除原图。

插图使用统一的方形构图、暖灰米色底、低饱和莫兰迪配色和扁平矢量风格。每个账号默认每天最多尝试 5 次，可用 `WORD_IMAGE_DAILY_QUOTA` 调整。留空 Key 或将额度设为 `0` 即可关闭新生成，已保存的图仍可查看。

## 看图回忆

从「今日回顾 → 看图回忆」进入。打开就能练内置题，也可切换到「用我的记忆图练习」。根据英文单词，从九宫格中选出符合该词释义的图片。题号旁的「多选」表示有两张或更多正确图。提交后可以查看每张图的英文单词和中文释义。

点题目底部的「对图片有疑问」可选择一张图重新生成，也可补充自己的理解。生成期间可以继续答题，新图成功后保存到当前账号，失败时保留原图。迁移 028 增加内置图替换记录。

## 查词

从电脑侧栏或手机顶部的放大镜打开「查词」。支持英文单词、短语和中文释义。系统优先查询已导入的词书，未收录时可点「用 AI 补查」。补查使用已配置的文字 AI，结果会标明来源。

## 自动朗读

- 默认开启。可在「偏好设置 → 学习环境」关闭，设置保存在本设备。手动喇叭可以重播或取消正在准备的音频。
- 单词、题号或会话改变时播放；仅提交答案不会重复朗读。暂停、退出、切换模式或页面隐藏立即取消过时请求和播放。
- 继续使用服务器 Kokoro，无需安装手机系统 TTS。短词音频最多缓存 24 条，按登录身份、接口、拼写和语速隔离，重播不重复请求服务器。
- 安卓 WebView 通过 WebSettings.setMediaPlaybackRequiresUserGesture(false) 支持自动播放，需安装新 APK 才能获得这一原生配置。浏览器仍可能要求先与页面交互，界面会提示点喇叭启用。
- 保持服务器原有朗读频率与并发限制。只对短暂 TTS_BUSY 最多重试 3 次，不自动重试频率限制或其他错误，不改变现有限额。

## 发布验证

单测覆盖免费字典的去重、许可、缓存和失败，个人生成内容隔离，音频缓存、晚到响应、自动播放拒绝与限流，以及跨组题号归零的播放身份。另通过手机尺寸和桌面尺寸浏览器验证答对/答错卡片、手动 AI 入口与自动发音开关。未连接实体手机，本次不把浏览器测试称为真机测试。
