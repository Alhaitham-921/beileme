# 情境任务、多角色与可选提示图

本轮仅在本地实现，尚未推送 GitHub 或部署正式站。账号、旧对话、旧学习记录及历史雅思数据均保留。

## 学习流程

认识任务词汇 → 多角色情境交流 → 情境小结巩固。词汇认识可以跳过，也不依赖文字 API；对话需要已配置的文字模型。搭配填空位于对话结束的小结中，不增加对话前的搭配关卡。

用户身份固定。多角色场景允许切换交谈对象。切换保留原对话、轮数和目标进度，并加载当前角色的提示图。每条消息记录说话角色或接收对象。模型可建议转接，由用户点击确认；生成提示词要求各角色遵守权限、共享条件与已确认事实，不代替用户作答。该约束依赖模型遵循，不能保证模型绝不混淆事实。

任务目标由模型判断，并要求引用本轮用户的连续英文原话。不存在的目标、虚构引文、中文求助、涉及已验证纠错的片段不能用于完成目标。手动结束、轮数到达上限、角色切换本身不等于通关。引文只能验证来源，不能替代对目标完成语义的人工校准。

## 奖励与巩固记录

- 全部目标完成：任务通关印记；基础酒店任务完成后开放“酒店改期挑战”。
- 目标独立完成、独立用出目标词，且本轮没有使用二级及以上求助：独立表达星。
- 至少24小时前在同主题其他任务中独立完成，并与当前任务具有相同的单词和确切义项：跨日迁移星。仅不同日期或重复同一任务不满足条件。

奖励对应任务表现，不代表英语等级、真实工作能力或经过实验验证的长期掌握。迁移星不证明中间没有额外学习或提示。小结可比较上一轮同类任务的独立用词数、求助次数。

小结包含词义选择与搭配填空。服务器判分并保存正确、错误、提示后答出、跳过；刷新可恢复，重复请求不重复记录，重练保留既往作答。词库能匹配时写入同义项的学习证据；不通过立即重练反复延长单词长期复习间隔。原有对话证据和 SRS 回流机制继续使用。

## 场景提示图

进入新场景或切换交谈对象时，自动读取当前场景和角色的提示图。首次进入且尚无图片时在后台生成，返回已生成过的角色时直接复用。可手动重新生成。自动生成和手动生成均使用文字 AI 和每日图片额度，对话可同时继续。

电脑端显示在对话右侧；900px及以下视口显示在对话上方，初始收起。展开后可以生成或查看；点击缩略图打开遮罩放大，支持关闭按钮、Escape、点击遮罩关闭，关闭后焦点返回原图片按钮。

文字模型先设计结构化线索，再使用现有生图服务生成并转成 WebP。约束包括：

1. 一个地点、一个时刻、一个视角，最多两个人、五件关键物体。
2. 每个目标词必须对应当前确切义项，不使用更容易画的其他词义；具体名词用物体，动词用动作，介词用参考物与空间关系。
3. 抽象词用当前场景中的道具或动作提示。配图旁用一两句中文介绍当前人物和画面里的词义线索。
4. 不把未做出的用户选择、协商成功或最终费用画成已经发生。
5. 禁止可读文字、字母数字、中文英文标签、答案句、品牌、水印及对话气泡。

程序校验线索与目标词义一一对应、长度和字段类型；不包含图像语义识别或 OCR 自动验收，不能保证输出图像完全遵循约束。待真实模型和人工验收后才能评价画面质量。

图片按账号、本轮任务和交谈对象保存。生成中的重复请求去重，其他角色的请求等已有任务完成后再提交。失败可手动重试。

## 历史错词选入与生成按钮修复

情境选词默认提供“错词本 · 全部历史”，复用账号私有的 `/words/collections?source=mistakes`，支持搜索英文和释义、每页30词翻页；今日错词、全部收藏仍可切换。跨页和跨来源保留所选词，最多5个；来源读取失败可重试，不阻断其他来源；慢请求不能覆盖新来源的结果。错词来源与现有错词本一致，不受今日日期或当前词书限制。

旧页面将需求不足10字直接作为禁用按钮条件，选词并不能解除。现改为按钮正常可点击：选词后允许需求留空，用户点击时补充默认日常情境需求，短需求也会保留后补充；没有选词且需求不足10字时，显示明确提示并聚焦输入框，不调用生成接口。每次真正生成前重新读取文字 AI 状态，避免使用进入页面时的旧配置结果；所有付费生成仍由用户点击触发。

已读取用户提供的 Cloudflare 网址完整公开首页，确认线上仍有 `disabled: ... || ...trim().length<10` 条件，且仅有今日错词和收藏两个来源。本轮只读取公开页面，没有读取用户账号、API Key 或调用真实模型；线上未更新。证据摘要在 `output/journey-20261119/public-button-verification.json`。

最新验证：668项自动化测试通过（82组），前端构建通过（155模块）；新增覆盖历史错词到生成的完整接口链路、跨来源和跨页选词保留、搜索、5词上限、迟到响应、单来源失败及空白需求处理。未发布线上、未推送 GitHub。
