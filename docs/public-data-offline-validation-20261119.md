# 公开研究与真实学习数据离线验证

执行日期：2026-11-19。对象为背了么的自测历史关联、复习及图词互动设计。独立研究目录 `output/public-research-20261119/` 保存来源元数据、原始文件、校验摘要和结果。本次没有连接线上数据库，没有导入外部用户成绩，没有改变产品评分或复习参数。

## 已完成与依据

已完整获取图词学习实验的四份公开参与者成绩表，共 341 名参与者，以及作者分析源文件、字段说明和许可元数据。四份表均核对发布方 SHA-256，重新计算 12 组论文报告的配对 t 统计量，均与论文保留两位小数的数值一致，容差 0.0051。

另取得 Duolingo 公开文件开头的 33,094 条完整真实学习记录，涉及 1,167 名匿名学习者，建立按学习者隔离、按时间向后测试的离线预测流程。它是受下载速度影响取得的连续前缀样本，**不是完整 1300 万条数据，也不是随机代表性样本**。该分析仅为流程及小样本探查。

## 1. 图词互动：公开实验的数值复核

来源：Chua & Pan (2026), [Duolingo-inspired pretesting with words and pictures improves vocabulary learning](https://pmc.ncbi.nlm.nih.gov/articles/PMC12965936/)，DOI `10.1186/s41235-026-00708-y`。原始数据与分析：[作者 OSF 项目](https://osf.io/s8gvp/)。OSF 项目许可元数据为 CC BY 4.0；没有下载或在产品中再发布第三方图包。

方法：只读取各文件 `ptl2exp1` 至 `ptl2exp4` 主结果表，保留作者清洗后的原始参与者记录。不混入猜对/猜错后条件化的敏感性分析表，也不混入主观偏好或成绩预测表。实验 2、4 按 `COND + ID` 确认参与者身份，避免把不同组相同编号当成重复或同一人。每项比较均在参与者内配对。

重新计算的“先尝试选择并得到正确反馈”减“直接阅读”的平均成绩差如下，单位均为**百分点**。这里按每个实验合并其组展示，不能再与分组结果相加：

- 实验 1，58 人：选项识别 +10.54，提示回忆 +10.15。
- 实验 2，123 人：选项识别 +11.47，提示回忆 +8.31。
- 实验 3，47 人：选项识别 +3.78，提示回忆 +10.17。
- 实验 4，113 人：选项识别 +6.10，提示回忆 +6.39。

计算参与者内差值，以固定种子 20261119 做 5,000 次参与者 bootstrap。实验 3 的选项识别差值 95% 区间为 -1.42 至 +9.22 个百分点，跨过零；不能说每个实验的每种任务都已证实改善。四项实验的提示回忆区间均在零以上。配对 t 值核对覆盖论文的全部 12 个单组比较；没有声称复现混合 ANOVA、贝叶斯因子或全部论文分析。脚本分别输出 dz 与 dAv 的明确定义，避免混淆不同效应量。

对本项目的依据：保留“先主动选择、提交后给出正确反馈”，并将选项识别与需要自行产出答案的任务分开记录。不能把图片选择正确直接计成独立运用或长期记牢。

适用边界：研究使用 36 个具体西班牙语名词，后测发生在约五分钟干扰任务后。它没有证明背了么的生成图片质量、介词与抽象词效果、7 天或 30 天保持率，也没有检验当前自编自测 A/B 卷。尝试选择条件的总学习时长还长于直接阅读，后续本地效果实验应控制总时长、材料、反馈和曝光次数。

## 2. Duolingo：历史数据预测的离线试验

来源：Settles & Meeder (2016), [A Trainable Spaced Repetition Model for Language Learning](https://aclanthology.org/P16-1174/)，DOI `10.18653/v1/P16-1174`。数据：[Harvard Dataverse，DOI 10.7910/DVN/N8XJME](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/N8XJME)。字段及原始算法说明：[作者官方仓库](https://github.com/duolingo/halflife-regression)。

许可已从实际 Dataverse 元数据核对为 **CC BY-NC 4.0**，与仓库代码的 MIT 许可不同。本次用于非商业离线研究，原始数据不纳入应用、账号库或 Git 追踪文件。若后续改变用途，需重新核对相应授权。

实际获取范围：官方文件全长 379,004,009 字节，发布方 MD5 为 `0a1cae5eb7ad4b0bd9c0de91d74fcced`。本次仅取得开头 956,764 字节，前缀 SHA-256 为 `cd55227b52f94979783ddca0a5ced9b978f7c174918db462ba5a3f9d4adfc13d`。对不完整 gzip 显式使用截断恢复，保留最后一个完整换行之前的记录并重新压缩；没有声称通过整个源文件 MD5。完整文件下载未完成。

样本覆盖 UTC 2013-02-28 18:28:01 至 20:43:39，约 2 小时 16 分钟。学习语言为英语 14,064 条、西班牙语 9,101 条、法语 4,079 条、德语 3,025 条、意大利语 2,151 条、葡萄牙语 674 条。历史间隔可能很长，但不能因此把本样本称为跨月连续追踪。

质量核对：33,094 行均通过字段完整性、历史正确数不超过历史次数、本轮正确数不超过本轮次数、正确比例与本轮次数一致、间隔非负及整行重复检查。`p_recall` 是一轮相关练习的正确比例，不是必然的单题 0/1。

拆分在建模前固定：按匿名学习者 ID 的 SHA-256 分成 80% 开发组和 20% 测试组。开发组前 70% 时间用于训练、70% 至 85% 时间用于验证；测试组只取最后 15% 时间。测试学习者完全不出现在训练和验证中，测试记录均晚于验证记录。

- 训练：18,695 条，715 名学习者。
- 验证：3,765 条，237 名学习者。训练与验证可包含同一学习者的先后记录。
- 最终测试：972 条，53 名学习者。
- 其余 9,662 条因学习者与时间隔离策略不用作上述三组，不能误报为全部用于测试。

比较四个预先定义的方法：训练集平均正确比例、个人历史平滑正确率、仅时间与学习语言的逻辑回归、增加历史正确和错误信息的逻辑回归。训练及验证阶段不使用当前轮答案作为特征，标准化只在训练集拟合，正则强度仅根据验证集交叉熵选择。外部历史字段代表预测前已知记录，不用未来结果回填。

最终测试每条记录等权的平均绝对误差 MAE，越低越好：

- 训练集均值：0.170928。
- 历史平滑正确率：0.280611。
- 时间与语言模型：0.173754。
- 历史、时间与语言模型：0.170185。

增加历史信息后的逐行 MAE 改善为 0.003569，但按学习者分别计算改善、每人等权后，仅为 0.000839；按 53 名测试学习者 bootstrap 的 95% 区间为 -0.003397 至 +0.004564，跨过零。**本样本不足以断言历史模型稳定更好**。简单累积历史正确率在这次样本中反而较差，不能直接作为当前能力评分。

这是自建的历史特征试验，不是作者 HLR 算法或论文分数的完整复现。没有将比例强行二值化再报告 AUC，也没有从本项目 SM-2 的复习间隔凭空推导“真实回忆概率”。当前只完成外部预测流程验证，尚未完成本项目复习调度效果验证。

## 3. 外部测验标准与本项目自测

仍可参考 Victoria University of Wellington 的 [官方词汇测验资源](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/vocabulary-tests) 区分词汇量测验和词频层级测验。官网允许 Updated VLT 的研究使用。网页工具能读取官方资源页，但本轮直接下载 Updated VLT B PDF 收到 403，未冒称已下载或分析该试卷的参与者数据。

本项目目前的中文选择题、抽题数量、义项和干扰项与外部测验不同，不能继承外部试卷的等值结论。以上两份学习研究也没有为我们自己的 A/B 题提供共同被试作答矩阵，因此未进行本地题目难度估计、试卷等值、精确词汇量换算或 CEFR 定级。

## 4. 本次结果如何用于开发

可直接采用的设计依据是：主动尝试后给正确反馈、识别和产出分开保存、关联旧错题与后续表现、保留多次记录而不只覆盖为最新一次。公开研究支持这些方向的合理性；不能保证某个具体阈值已经有效。

本次不根据小样本替换 SM-2、调整“已掌握”天数或提高 AI 的结论强度。自测继续可选，无 API 仍有基础历史比较，AI 解释由用户点击生成并保存。

后续有三项明确缺口：获取更广时间段及学习者的外部复习数据后再做稳健预测比较；用本项目同一批真实参与者完成顺序平衡的 A/B 试测；用相同时长和曝光次数的本地随机对照，分别测即时、7 天和 30 天识别与回忆。后两项无法由当前外部数据直接替代。都不得用模拟用户或外部用户填充平台真实成绩。

## 复现与文件

脚本不加载项目私有环境、不连接数据库，也不调用 AI、邮件或在线推理 API。下载文件仅在被 Git 忽略的研究目录保存。

```powershell
node scripts/research/download-public-data.mjs --sample-bytes=956764
python scripts/research/analyze-public-data.py
```

Python 依赖：numpy、pandas、openpyxl。本次实际环境版本保存在 `offline-results.json`。完整下载另用 `--full`，仅在完成全文件大小与发布方 MD5 校验后才可称全量取得。默认命令只准备连续前缀样本。

`download-manifest.json` 记录下载成功、失败、文件长度、摘要与来源；`image-study-osf-inventory.json` 保留作者文件清单及许可；`sample-provenance.json` 标明不完整源文件的范围；`offline-results.json` 保存全部结果、拆分与模型参数；`image-study-reproduction.csv` 为可复核的实验汇总。没有修改原始工作簿，也没有把派生结果当作新原始数据。
