# 随对话变化的接话参考

情境对话中的「不会说？」和接话思路、参考回复、完整示范句均调用账号当前的文字 AI，根据场景角色、最新完整对话、用户尚未提交的草稿和当前难度生成。参考生成不再读取场景预设的单词例句或词组，也不增加对话轮数。

「参考用词」默认选择「暂时不用记忆词」，优先自然回应对方最新的问题。也可选择一个本轮记忆词，或点上方词卡；AI 会在当前接话中使用这个词的场景义项，不重新开始点餐、开户等旧任务。再次点选中的词卡可取消选词。

- 接话思路：中文思路与一段可用英文短语或句子开头。
- 参考回复：一句简短自然的英文。
- 完整示范句：一至两句可直接说出的英文。

有草稿时结合当前问题翻译或完善草稿；无草稿时给一个合理的可选回答。参考只是示范，用户可修改后发送。只有实际发送的表达才能计入使用情况；照着当前或历史参考复述仍算提示后表达，不误记成独立用出。

## 接口和记录

`POST /api/v1/practice/sessions/:id/help`：

```json
{"level":3,"useMemoryWord":false,"text":"我想喝茶","expectedTurn":2}
```

指定词时发送 `useMemoryWord:true` 和 `word`。仅允许当前场景词，保留准确义项；旧客户端不传 `useMemoryWord` 时仍按指定词或待练词生成参考。关闭用词要求时忽略遗留的 `word` 参数。

所有参考均使用会话操作锁、轮数校验、账号 AI 调用额度和消耗统计。生成失败不覆盖已有参考，不提交草稿，也不增加帮助事件；有效的英文参考不会因可选中文提示或翻译格式异常而丢弃。仅英文主体或必选词不符合要求时，自动按参考专用格式修复一次。

不需要数据库迁移。现有对话和帮助记录继续兼容。
