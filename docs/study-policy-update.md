# 学习流程与判定调整（2026-11-02）

现状核查：每日队列先复习后新词；答对超过3秒降为quality3，错因服务也硬编码3秒，而统计页用4秒，口径不一致。学习页时长还含阅读选项、朗读和切后台，不能等同纯回忆速度。

调整：提供先复习再学新词和直接新词；服务端直接新词模式不查询复习队列。跳过不算完成；新词仍遵守今日目标量，完成后可额外学一组。已有会话可继续或通过选择学习方式重排，已答流水保留。

正常回忆答对quality4，不因时间降级；主动勾选不确定才quality3；答错quality1。长期掌握仍按既有连续复习与间隔推进，不把单次选择正确当成已掌握。记忆强度移除速度权重，以连续正确40%、难度因子30%、历史正确率30%计算。权重和21天掌握门槛属于产品启发式，不是研究证实的统一阈值。现有历史进度不批量重写，后续作答使用新规则。

对比：Anki提供新词/复习顺序选项，并区分Again/Hard/Good/Easy，正常回忆可选Good，不要求即时答出；墨墨强调复习负担随新词累加，因此保留复习提醒，但不替用户强制锁新词。未拿到其他软件内部算法，不声称复刻其阈值。

研究：Karpicke与Roediger的外语词汇实验支持重复提取对延迟记忆有益，不提供适用于本项目多选题的3秒掌握分界。因此这次选择去除自动秒数降级，而不是把3秒换成另一个无依据数字。
