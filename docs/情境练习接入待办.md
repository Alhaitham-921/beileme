## 你现在需要做的事

- [ ] **确认文字对话模型能正常调用。** 沿用项目现有 AI 设置和 Key，先在设置页测试连接。语音识别另用下面的 `SPEECH_*` 配置；文字模型可用不代表它支持语音识别。
- [ ] **选定语音识别供应商并创建 API Key。** 需要支持 `POST /audio/transcriptions`、Bearer 鉴权、multipart 文件上传、返回 `{ "text": "…" }`。下表提供两种配置。只需选择一种，不必都注册。
- [ ] **开通所选模型权限、按供应商要求完成账户验证和计费，并设置消费预算/告警。** 先确认控制台中模型实际可用及当前价格，再充值。账户验证、付款和密钥创建需要你在供应商控制台完成。
- [ ] **把语音配置填入本机 `server/.env` 或部署平台的服务端环境变量，重启后端。** 不要把 Key 发到聊天里、提交 Git、填写到前端 `VITE_*` 或打包进 HTML。
- [ ] **允许浏览器和操作系统使用麦克风。** 本机在 `http://localhost:5173` 测试；手机或外网部署要用 HTTPS。首次点麦克风时允许权限，拒绝后在浏览器网站设置中重新打开。[浏览器权限与安全上下文说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
- [ ] **亲自完成一次真实录音验收。** 用下文的验收清单在实际设备上测试。自动化测试已模拟服务商和麦克风生命周期，不能代替真实设备和网络测试。

## 语音供应商配置

| 选择 | 注册/Key | 服务端配置 | 使用条件 |
| --- | --- | --- | --- |
| OpenAI | [API 控制台](https://platform.openai.com/)、[官方快速开始](https://developers.openai.com/api/docs/quickstart) | `SPEECH_BASE_URL=https://api.openai.com/v1`，`SPEECH_MODEL=gpt-4o-mini-transcribe` | 先确认账户、使用地区和部署方式在供应商支持范围内。[官方支持地区](https://developers.openai.com/api/docs/supported-countries)当前未列出中国大陆，不应把境内直接可用视为默认前提。 |
| 硅基流动（国内可评估的兼容方案） | [官方控制台](https://cloud.siliconflow.cn/) | `SPEECH_BASE_URL=https://api.siliconflow.cn/v1`，`SPEECH_MODEL=FunAudioLLM/SenseVoiceSmall` | 官方提供相同转写路径、Bearer Key、`file`/`model` 上传和 `text` 返回。[官方语音识别文档](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)未明确保证每种浏览器录音编码及中英混说质量，需用真实 Chrome WebM、Safari MP4 和混说录音验收。 |

OpenAI 的转写接口接收音频文件和模型名，本项目不固定输入语言，保留中文混说给对话模型判断求助。上传方式按 [OpenAI 官方转写 API](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create) 实现。兼容供应商的模型名、价格与格式支持以其当前文档和实测为准；若拒收浏览器容器，需要增加对应供应商适配或音频转码，不能只改文件扩展名。

在 `server/.env` 添加或修改（真实 Key 自行填写）：

```dotenv
# 独立语音密钥，不复用 AI_API_KEY
SPEECH_API_KEY=
SPEECH_BASE_URL=https://api.openai.com/v1
SPEECH_MODEL=gpt-4o-mini-transcribe
SPEECH_TIMEOUT_MS=30000
SPEECH_MAX_BYTES=2097152
SPEECH_MAX_SECONDS=60
SPEECH_DAILY_QUOTA=100
SPEECH_PER_MINUTE_QUOTA=6
```

然后执行 `npm run server`（前端开发另执行 `npm run dev`）。语音状态通过登录后的 `/api/v1/speech/status` 检查；不会返回 Key。未填写 Key 时返回未配置，麦克风入口会提示继续打字。默认朗读使用浏览器 `speechSynthesis`，可调语速，无需另外申请 TTS API；可用音色和效果随浏览器/系统而变化，部分系统音色可能需要联网。[SpeechSynthesis 文档](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)

## 上线部署待办

- [ ] **准备后端和 MySQL，运行迁移。** 在项目根目录执行 `npm run db:migrate`，确保新建的情境对话数据表部署到目标数据库。部署前备份数据库，使用项目现有的数据库和鉴权配置。
- [ ] **配置 HTTPS、前端 API 地址和 CORS。** 前端通过现有 API 客户端访问后端；HTTPS 页面对应的 API 也应可安全访问。若嵌在 iframe，宿主页还需要允许 microphone 权限。[MDN 说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
- [ ] **检查反向代理上传上限和超时。** 默认音频 2 MB 经 Base64 传输约 2.67 MB，应只给语音转写路径留足约 3 MB 请求体；其他 API 维持原上限。代理超时应大于服务端转写超时并覆盖上传时间。
- [ ] **在真实部署服务器验证供应商可达性。** 浏览器只把录音传给自己的后端，由后端调用供应商；需确认服务器出站 HTTPS、账户地区和选用服务符合供应商要求。
- [ ] **公开使用前确认录音说明及供应商数据处理方式。** 录音在用户停止后上传用于转写；本应用不把录音写磁盘/数据库，供应商自身的留存政策需单独确认。转写文本在用户确认发送后按普通对话记录保存。客户端取消识别只忽略结果，已经上传并开始处理的请求仍可能产生费用。

## 当前实现的限制和后续工程待办

- 浏览器录音自动在 60 秒停止；切后台、取消、离开页面会释放麦克风。后端检查客户端上报时长、音频容器签名、严格 Base64 和最大字节数，上游调用限制 30 秒。**后端尚未解码媒体核实真实音频时长**；不能将客户端时长字段当成防恶意费用的硬边界。公开运营前可加入受限的媒体探测/解码核验；当前字节、请求次数和并发限制仍生效。
- 默认每用户每日 100 次、每分钟 6 次、同时 1 次语音识别。服务商失败的请求也占次数，避免自动重复消耗；语音接口不自动重试付费请求。当前额度储存在进程内存，重启会重置，多实例之间不共享。**正式多实例部署前应迁到 MySQL/Redis 共享计数，并增加服务商总预算和监控。**
- 情境对话当前每日最多 10 个新会话、200 次文字模型调用，每会话最多 16 次求助、8 轮回答；用量写在独立 `dialogue_daily_usage` 表。情境调用和语音识别目前未并入原有 AI 成本看板；观察真实成本请查供应商控制台。上线前可统一成本统计和管理员配额配置。
- 复习优先匹配当前词书；首版场景目标词另有 `dialogue-core` 基础词库，即使当前词书未收录也能自动加入复习，不会更换用户正在学习的词书。对话额外出现、所有词库均未收录的单词会在报告中列出，并保留短句练习。
- 浏览器格式按能力选择 WebM/Opus、MP4 或 Ogg/Opus。系统自带 Web Speech 识别服务没有作为隐式备用通道，避免在用户不知情时上传到另一个服务；不支持录音时可继续文字输入。
- 首版不包含发音评分、长对话记忆和自定义角色。语音转写错误应先在输入框修改，再提交；发音好坏不计入词汇掌握度。

## 真机验收清单

- [ ] 无 Key：明确显示未配置，文字输入、对话和报告仍正常。
- [ ] 允许麦克风后录一句英文，停止后识别内容出现在输入框，**不会自动发送**；修改一处后能手动发送。
- [ ] 录制 “I want to 在河边走一走” 一类混说，确认中文未被转写自动翻译掉，对话求助能得到英文示范。
- [ ] 拒绝权限、没有麦克风、设备被占用、断网、服务商报错都能得到清楚提示，继续打字不会被阻断。
- [ ] 点取消、切场景、结束对话、离开页面、切后台后，浏览器麦克风指示熄灭；迟到的转写结果不会覆盖新场景输入。
- [ ] 录音到时自动结束；频繁提交和耗尽日额度会被限制，不会无限调用。
- [ ] AI 气泡可朗读，语速随练习水平调整；切场景/结束后朗读停止。
- [ ] 在实际使用的桌面 Chrome/Edge、Android Chrome 和 iOS Safari 分别验证格式、权限和中英混说；只声明已测通过的平台。
