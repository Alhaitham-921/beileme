内置书架由 2 本扩充为 14 本：爱丽丝梦游仙境、傲慢与偏见、金银岛、福尔摩斯历险记、秘密花园、绿野仙踪、小妇人、简·爱、了不起的盖茨比、圣诞颂歌、八十天环游地球、鲁滨孙漂流记、汤姆·索亚历险记、巴斯克维尔的猎犬。

新增书籍采用 Standard Ebooks 官方完整正文，按源 EPUB spine 顺序导入，保留文学正文、序言、分部及尾注，省略出版工具页。每本保留原始授权声明、源提交与内容摘要；八十天环游地球标记为 George Makepeace Towle 英文译本。章节数包含序言、分部或尾注，因此书架显示“节”。

`import-extra-classics.py` 可从官方检出目录重建新增书籍；下载慢时可传 `--fallback-sources` 指向只包含正文的固定提交快照，其 SOURCE_COMMIT 记录版本，本轮快照逐文件核验 Git blob SHA1。不是用 AI 编写小说内容。

“听读空间 → 英文书籍 → 添加书籍”支持 TXT 与未加密 EPUB：单文件最多 8 MB、提取文字最多 2 MB、每账号最多 20 本与合计 20 MB 文字。TXT 支持 UTF-8、带 BOM 的 UTF-16 及 GB18030；EPUB 读取本地正文、内嵌文字和目录，不加载脚本、样式或远程资源，也不提取图片。

个人书籍仅所属账号可见；书架只查询元信息，章节读取、进度、声明、AI 解释和删除均校验所有权。重复正文导入返回已有书籍并保留进度；移除个人书籍只删除该书及对应阅读位置，保留本机文件和其他账号/学习数据。

新增 `045_personal_reading_books.sql` 只添加表。大文件 JSON 解析仅放宽到已登录的导入接口，其他普通接口保持原 1 MB 上限。ZIP/XML 限制扩展大小、条目数、深度和节点数，拒绝声明实体及加密正文。AI 请求仍走统一文字接口适配层；导入不调用 AI，使用解释时才按用户偏好和主动点击发送相关文本。
