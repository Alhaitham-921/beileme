# Cinematic landscape backgrounds

Generated on 2026-10-15 using the built-in `image_gen.imagegen` tool (default built-in mode from the imagegen skill). No external stock assets or fallback CLI were used.

All images are opaque landscape photographs generated for this project. Final files were visually inspected and encoded as optimized progressive JPEG at quality 86; the original composition and color were preserved. The application supplies its own dimming overlay for readable interface text.

- `moonlake.jpg`: moonlit alpine lake; default atmosphere.
- `mist.jpg`: misty forest valley; dark sage atmosphere.
- `coast.jpg`: quiet coastal bay at dusk; muted blue atmosphere.
